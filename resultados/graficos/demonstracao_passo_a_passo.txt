DEMONSTRAÇÃO PASSO A PASSO — produto matriz-vetor  n = N_Mat(1:4) · w
Dados reais: 4 primeiros estudantes da base integrada (escala 0–10).

1) Matriz original (4 x 3; colunas = P1, P2, P3 de Matemática):
[    2,5     3,0     3,0 ]
[    2,5     2,5     3,0 ]
[    3,5     4,0     5,0 ]
[    7,5     7,0     7,5 ]

2) Operação: produto de matriz (4x3) por vetor de pesos w (3x1) = (0,3; 0,3; 0,4)^T -> resultado 4x1.
   Compatível porque o nº de colunas da matriz (3) = nº de componentes de w (3).

3) Cálculo de cada elemento  n_i = a_i1*w1 + a_i2*w2 + a_i3*w3:
   n_1 (E001) = 2,5·0,3 + 3,0·0,3 + 3,0·0,4 = 0,75 + 0,90 + 1,20 = 2,85
   n_2 (E002) = 2,5·0,3 + 2,5·0,3 + 3,0·0,4 = 0,75 + 0,75 + 1,20 = 2,70
   n_3 (E003) = 3,5·0,3 + 4,0·0,3 + 5,0·0,4 = 1,05 + 1,20 + 2,00 = 4,25
   n_4 (E004) = 7,5·0,3 + 7,0·0,3 + 7,5·0,4 = 2,25 + 2,10 + 3,00 = 7,35

4) Resultado: n = (2,85; 2,70; 4,25; 7,35)^T

5) Interpretação: cada componente é a nota ponderada de Matemática do estudante; valores abaixo de 5,0 indicam reprovação.
